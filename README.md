# Vietnam ↔ Sweden Schedule

A single-page website with two linked schedules (Vietnam and Sweden). Events are stored once, as a real moment in time, and shown in each time zone. Edit the time on either side and the other updates.

- Live clocks and current time difference (6h in winter, 5h when Sweden is on summer time)
- Click an empty slot to add an event, click an event to edit it
- Edit dialog has both Vietnam and Sweden time fields, linked together
- Night hours shaded, "now" line shown
- Saved in your browser, with "Copy share link", Export and Import for sharing

## Put it on GitHub Pages

1. Create a new repository on GitHub (e.g. `vn-se-schedule`).
2. Upload `index.html` and `README.md` (Add file → Upload files).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. After a minute your site is live at `https://YOUR-USERNAME.github.io/vn-se-schedule/`.
